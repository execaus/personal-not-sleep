# Personal Not Sleep

Нативная утилита macOS для предотвращения простоя Mac и выключения дисплея. Живёт в строке меню и использует штатные `IOPMAssertion` от Apple. Интерфейс на русском. Исходный код открыт под лицензией MIT.

## Возможности

- **Вручную:** «Включить до выключения» и «Выключить» в строке меню.
- **Таймер:** пресеты 15, 30, 60 и 120 минут; в настройках можно ввести от 1 до 10 080 минут (7 дней).
- **Расписание:** несколько повторяющихся интервалов с любым набором дней недели и временем начала/окончания; окончание раньше начала означает следующий день.
- **Автозапуск:** переключатель в настройках регистрирует приложение через `SMAppService.mainApp`, чтобы расписание могло сработать после входа пользователя в macOS.
- **Обновления:** ручная проверка в меню и отключённая по умолчанию автоматическая проверка в настройках. После включения Sparkle периодически проверяет GitHub Releases и предлагает подписанное обновление.

Значок солнца означает активное удержание, луны — выключенное. Меню и окно показывают причину и время окончания. При ручном выключении в ходе интервала расписания этот интервал остаётся выключенным до завершения; следующий интервал включится как обычно. Ручной режим, срок таймера, расписание и подавленные текущие интервалы хранятся в локальных `UserDefaults`, поэтому перезапуск приложения не отменяет выбранный режим. Изменения часового пояса и пробуждение пересчитываются; обычная проверка выполняется раз в 10 секунд.

## Сборка

Нужны macOS 14 или новее, Command Line Tools с Swift 6 и системная утилита `codesign`. При первой сборке SwiftPM получает зафиксированную версию Sparkle 2.10.0; после кэширования повторная сборка не требует сети. Иконка генерируется из локального AppKit-скрипта.

```sh
zsh scripts/make-app.sh
open dist/PersonalNotSleep.app
```

Готовое приложение — `dist/PersonalNotSleep.app`. Скрипт собирает релизный Swift Package, включает иконку и Sparkle, затем ставит локальную ad hoc подпись. Для распространения за пределами своего Mac предпочтительны Developer ID подпись и нотариализация Apple. Если Gatekeeper блокирует локально собранный `.app`, откройте его через Finder с явным подтверждением системы. Автозапуск следует включать в уже установленной на постоянное место копии `.app`; перемещение приложения после регистрации может нарушить запуск.

## Обновления и выпуск

Приложение работает офлайн, пока пользователь не нажал «Проверить и установить обновление…» или не включил «Автоматически проверять обновления» в настройках. При проверке Sparkle обращается по HTTPS к `https://github.com/execaus/personal-not-sleep/releases/latest/download/appcast.xml`, проверяет подпись ленты EdDSA и при наличии новой версии скачивает архив GitHub Release. Подпись архива проверяется до распаковки; установка предлагается пользователю, автоматическая установка отключена. Ни аналитику, ни сетевые функции для основного режима приложение не содержит.

Версия 0.1.0 была выпущена без Sparkle. Для перехода с неё на 0.2.0 может понадобиться ручная установка `.app`. Последующие версии можно получать через встроенное обновление, если релиз опубликован с подписанной лентой и архивом.

Локальная подготовка релиза:

```sh
zsh scripts/make-release.sh
```

Скрипт создаёт `release/PersonalNotSleep-0.2.0-macos-arm64.zip`, `release/appcast.xml` и `release/SHA256SUMS`. Закрытый ключ EdDSA хранится только в Связке ключей macOS под учётной записью Sparkle `personal-not-sleep`; скрипт читает его через `generate_appcast`. Публичный ключ находится в `Info.plist`. Для следующего релиза нужно увеличить `CFBundleShortVersionString` и `CFBundleVersion` в `scripts/make-app.sh`, добавить заметки `release/vX.Y.Z.md`, собрать и проверить архив, затем опубликовать архив и **подписанный** `appcast.xml` как assets одного GitHub Release. Не меняйте ленту после подписи. При смене Mac безопасно перенесите закрытый ключ отдельно; потеря ключа нарушит непрерывность обновлений. Нижеописанная локальная сборка ничего не публикует.

## Проверка логики

```sh
CLANG_MODULE_CACHE_PATH="$PWD/.build/clang-cache" swift run --disable-sandbox PersonalNotSleepCheck
dist/PersonalNotSleep.app/Contents/MacOS/PersonalNotSleep --window-lifecycle-check
codesign --verify --strict dist/PersonalNotSleep.app
```

Если папка синхронизируется через File Provider и `codesign` сообщает о `com.apple.FinderInfo`, удалите этот добавленный файловой системой атрибут командой `xattr -d com.apple.FinderInfo dist/PersonalNotSleep.app` и повторите проверку. Скрипт очищает атрибуты перед подписью, но синхронизация может добавить их позже. `make-release.sh` отдельно проверяет распакованный архив.

`PersonalNotSleepCheck` проверяет границы интервалов, дни недели, переход через полночь, ручное выключение посреди расписания, следующий интервал, истечение таймера и некорректное правило. `--window-lifecycle-check` дважды открывает и закрывает окно настроек, проверяя освобождение старого содержимого и сохранность модели. Это локальные проверки без изменения системных настроек сна. Реальную работу IOPM и автозапуска проверяйте вручную на целевом Mac: включите режим и выполните `pmset -g assertions`, затем выключите и проверьте исчезновение assertions.
