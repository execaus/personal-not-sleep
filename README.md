# Personal Not Sleep

Нативная утилита macOS для предотвращения простоя Mac и выключения дисплея. Живёт в строке меню и использует штатные `IOPMAssertion` от Apple. Интерфейс на русском. Исходный код открыт под лицензией MIT.

## Возможности

- **Вручную:** «Включить до выключения» и «Выключить» в строке меню.
- **Таймер:** пресеты 15, 30, 60 и 120 минут; в настройках можно ввести от 1 до 10 080 минут (7 дней).
- **Расписание:** несколько повторяющихся интервалов с любым набором дней недели и временем начала/окончания; окончание раньше начала означает следующий день.
- **Автозапуск:** переключатель в настройках регистрирует приложение через `SMAppService.mainApp`, чтобы расписание могло сработать после входа пользователя в macOS.

Значок солнца означает активное удержание, луны — выключенное. Меню и окно показывают причину и время окончания. При ручном выключении в ходе интервала расписания этот интервал остаётся выключенным до завершения; следующий интервал включится как обычно. Ручной режим, срок таймера, расписание и подавленные текущие интервалы хранятся в локальных `UserDefaults`, поэтому перезапуск приложения не отменяет выбранный режим. Изменения часового пояса и пробуждение пересчитываются; обычная проверка выполняется раз в 10 секунд.

## Сборка

Нужны macOS 14 или новее, Command Line Tools с Swift 6 и системная утилита `codesign`. Сеть и внешние пакеты не нужны.

```sh
zsh scripts/make-app.sh
open dist/PersonalNotSleep.app
```

Готовое приложение — `dist/PersonalNotSleep.app`. Скрипт собирает релизный Swift Package, упаковывает `.app` и ставит локальную ad hoc подпись. Для распространения за пределами своего Mac нужна собственная Developer ID подпись и нотариализация Apple. Если Gatekeeper блокирует локально собранный `.app`, откройте его через Finder с явным подтверждением системы. Автозапуск следует включать в уже установленной на постоянное место копии `.app`; перемещение приложения после регистрации может нарушить запуск.

## Проверка логики

```sh
CLANG_MODULE_CACHE_PATH="$PWD/.build/clang-cache" swift run --disable-sandbox PersonalNotSleepCheck
codesign --verify --strict dist/PersonalNotSleep.app
```

Если папка синхронизируется через File Provider и `codesign` сообщает о `com.apple.FinderInfo`, удалите этот добавленный файловой системой атрибут командой `xattr -d com.apple.FinderInfo dist/PersonalNotSleep.app` и повторите проверку. Скрипт очищает атрибуты перед подписью, но синхронизация может добавить их позже.

`PersonalNotSleepCheck` проверяет границы интервалов, дни недели, переход через полночь, ручное выключение посреди расписания, следующий интервал, истечение таймера и некорректное правило. Это проверка логики без вмешательства в системный сон. Реальную работу IOPM и автозапуска проверяйте вручную на целевом Mac: включите режим и выполните `pmset -g assertions`, затем выключите и проверьте исчезновение assertions. Не используйте такую проверку на рабочей машине без согласования её политики питания.
