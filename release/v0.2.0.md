# Personal Not Sleep 0.2.0

- Исправлено повторное открытие настроек: после закрытия окно и его SwiftUI-представление освобождаются, следующее открытие создаёт новое окно с сохранёнными настройками.
- Добавлена нативная иконка приложения для Finder и системных представлений.
- Добавлены проверка и установка подписанных обновлений через Sparkle. Ручная проверка доступна в строке меню; автоматическая проверка включается отдельно в настройках и выключена по умолчанию.
- Обновления загружаются только из GitHub Releases проекта; лента и архив проверяются EdDSA-подписью до установки. Других сетевых функций нет.

Версия 0.1.0 не содержала механизма обновления: переход на 0.2.0 может потребовать ручной загрузки и замены приложения. После установки 0.2.0 последующие выпуски смогут использовать Sparkle.
