# Безопасность и границы

Personal Not Sleep использует только системный API IOKit Power Management (`IOPMAssertionCreateWithName`). Он просит macOS не усыплять Mac по бездействию и не гасить дисплей по бездействию, пока приложение работает и режим активен. При выключении assertions освобождаются. macOS может отказать в создании assertion; интерфейс покажет ошибку. Эти запросы не имеют приоритета над политиками хоста.

Утилита **не разблокирует экран**, не препятствует автоматической блокировке, явному сну, выключению, принудительному сну, закрытию крышки ноутбука и корпоративным политикам. Удержание включённого дисплея может увеличить энергопотребление и нагрев. Для проверки поведения на конкретной машине используйте `pmset -g assertions`; приложение не обещает обойти настройки организации.

Единственная внешняя зависимость — Sparkle 2.10.0. По ручной команде или после явного включения автоматической проверки Sparkle обращается к GitHub за лентой и архивом обновления. Автоматическая проверка выключена по умолчанию; автоматическая установка и системное профилирование выключены. Лента и заметки проверяются EdDSA-подписью, архив проверяется до распаковки. Другая работа приложения не использует сеть. При сетевом обращении GitHub видит обычные сетевые данные соединения, в том числе IP-адрес. Нет аналитики, перехвата клавиатуры, мыши, ввода, Accessibility, микрофона, камеры, имитации нажатий или фонового демона. Отдельный сетевой аудит собранного приложения на целевом Mac может быть частью процедуры организации.

В `UserDefaults` текущего пользователя сохраняются правила расписания, флаг ручного режима, срок таймера и идентификаторы подавленных текущих интервалов. Там нет истории активности, вводимого текста или рабочих данных. Системная служба входа хранит регистрацию автозапуска, если пользователь её включил.

Скрипт сборки ставит ad hoc подпись для локальной проверки. Это не Developer ID подпись и не нотариализация. Для публичных бинарных релизов предпочтителен отдельный процесс Developer ID подписи, нотариализации и проверки. Закрытый EdDSA-ключ Sparkle находится в локальной Связке ключей под именем `personal-not-sleep` и не добавляется в Git. Публичный ключ встроен в приложение. Для следующих выпусков требуется тот же закрытый ключ; его потеря сделает обновление установленных копий проблематичным. Репозиторий не содержит секретов или внешних бинарников, кроме нативного ресурса иконки.

Об уязвимостях сообщайте владельцу проекта через приватный канал GitHub, если он доступен; не публикуйте секреты или данные устройства в issue.
